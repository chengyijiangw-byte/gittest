### 1.3 网站组成

![](images/JSD2404-基础知识模块-image-12.png)

1. 用户通常使用浏览器（Browser）或客户端（Client）访问网站服务

2. 用户在展示出来的页面上做操作，一旦操作就会给对应的 WEB 服务器发送请求

3. WEB 服务器在接收到请求后，会按照预设的业务逻辑对请求进行处理

4. 期间涉及到数据的增删改查，还需要访问数据库服务器

5. 最后，WEB 服务器会将处理好的结果响应给用户端

6. 用户端将拿到的结果渲染出页面展示给用户看

注意：目前我们的 WEB 服务器（Tomcat）与数据库服务器（MySQL）在同一台 PC 上

## 2. 网页基础

**什么是前端和后端**

* 前端和后端是软件开发中的两个重要组成部分，它们会涉及到不同的技术和任务

* 前端主要关注用户**页面**和用户交互（页面相关）

* 后端主要关注服务器端的业务逻辑和服务可靠性，包括**处理业务请求、存储数据、保证服务稳定可靠**等等

### 2.1 什么是 WEB 前端

指使用 HTML、CSS、JavaScript 等技术，根据设计师提供的网页标注图进行代码编写，并将其转换为浏览器可以识别的网页界面，俗称网页。

### 2.2 基本概念

HTML（Hyper Text Markup Language）超文本标记语言，**<span style="color: inherit; background-color: rgba(255,246,122,0.8)">负责网页的内容</span>**

超文本： 除了文本以外，我们还可以向网页中插入图片、超链接、表格、表单、音频、视频等等

目前我们学习的版本是最新的 HTML5，简称 H5

1. HTML 由大量的标记/标签构成，分为：

2. 双标记标签：`<head></head>`

3. 单标记标签：`<br/>`或 `<br>`，两种写法都可以

4. 完整的网页结构：

```html
<!-- 表示当前文档是html5版本 让浏览器使用h5的规范解析 -->
<!DOCTYPE html>
<!--表示网页的开始与结束 lang="en"表示网页是一个英文网站 zh表示中文-->
<html lang="en">
<!--网页头部,存放一些配置信息-->
<head>
    <meta charset="UTF-8"> <!--配置编码,为了认识中文-->
    <title>我是网页标题</title> <!-- 配置网页的标题 -->
</head>
<body> <!--网页展示的内容-->
第一个网页的内容
</body>
</html>
```

* HTML 文件的后缀名是 <span style="color: rgb(36,91,219); background-color: inherit">.html</span> 或 <span style="color: rgb(36,91,219); background-color: inherit">.htm</span>，会按顺序从上往下、从左往右依次解析执行

![](images/JSD2404-基础知识模块-image-9.png)

* HTML 属性

<span style="color: rgb(216,57,49); background-color: inherit">属性：</span>也称为特征，描述标签某一方面的特点

html 有很多的属性和值，用来修改元素的样式和状态

<span style="color: rgb(216,57,49); background-color: inherit">写法：</span><标签 属性名 1="属性值 1" 属性名 2="属性值 2">\</标签>

<span style="color: rgb(216,57,49); background-color: inherit">要求：</span>

1. 属性的声明必须在开始标记里

2. 一个元素可能不只有一个属性，多个属性之间使用空格隔开

3. 多个属性之间不区分先后顺序

4. 属性名与属性值之间使用等号连接

5. 属性值要包裹在引号中

6. 单值属性：只有一个与属性名同名值，值可以省略不写，比如 readonly 只读

### 2.3 注释

1. 用来解释代码且不会执行的文本

2. 注释格式： `<!-- 被注释掉的内容 -->`

3. 快捷键： Ctrl+/ 添加注释，再按一次取消注释

4. 注释不能嵌套注释，也不可以写在标签里！

### 3.2 分区元素

分区标签：可以理解为一个区域，对多个具有相同或相似结构的标签进行统一管理

* `<div></div>`块级分区

* `<span></span>`行内分区

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>分区元素</title>
</head>
<body>
<!--行内分区元素 span不会换行 用来选中一行中的一部分 -->
我是JSD240328班级的<span style="color:red;">小可爱</span>
<hr>
<!--块级分区元素 独占一行 默认宽度为父级宽度的100% 高度为0-->
<div></div>
我是文字
<div>我是文字</div>
我是文字
</body>
</html>
```

**HTML5 新增了一些带有语义的分区标签**

* `<header></header>`定义网页或一个区域的头部

* `<nav></nav>`定义网页的导航部分

* `<main></main>`定义网页的主要内容

* `<section></section>`定义网页的一个区块或章节

* `<article></article>`定义网页中独立完整的内容，比如博客文章或新闻报道

* `<aside></aside>`定义网页的侧边栏或者附属信息

* `<footer></footer>`定义网页或一个区域的页脚部分

![](images/JSD2404-基础知识模块-image-4.png)

### 3.3 URL 路径

**<span style="color: rgb(216,57,49); background-color: inherit">URL</span>**（<span style="color: rgb(216,57,49); background-color: inherit">U</span>niform <span style="color: rgb(216,57,49); background-color: inherit">R</span>esource <span style="color: rgb(216,57,49); background-color: inherit">L</span>ocator）统一资源定位符，俗称路径，用来标识资源的位置

#### 3.3.1 **相对路径**

1. 从当前 html 文件的位置出发去找资源

2. 如果 html 与资源在同一个目录下，直接写资源的名字，如：1.png

3. 如果资源在 html 的下一级目录，先写目录名再写目录里的资源，如：img/2.png

4. 如果资源在 html 的上一级目录，先回到上一级再找资源，如： ../3.png

#### 3.3.2 **绝对路径**

从根目录处开始找资源，不需要当前文件的位置

1. 优点：节省本地服务器的存储空间&#x20;

2. 缺点：资源不稳定 如果远程服务器删除此资源，本地服务器就引用不到了,且并不安全

3. 网络资源：从协议开始，如： <https://cdn.tmooc.cn/bsfile//courseImg///f044221ee737404e91584a4d083764bd.png>

### 3.4 图片插入

*img 标签用来向页面插入图片&#x20;*

* *src 表示资源的路径&#x20;*

* *alt 表示图片无法显示时的替代文本&#x20;*

* *title 鼠标悬停时显示的描述文本*

* 图片本身有大小，修改图片宽高时要注意图片本身的宽高比 如果设置的宽高不符合图片本身的宽高比，图片会变形--图片比例失真&#x20;

* **<span style="color: rgb(46,161,33); background-color: inherit">解决方案：</span>**&#x5BBD;或者高只设置一个，另外一个会自动随之更改

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>图片插入</title>
</head>
<body>
<!--
从当前文件出发去找资源:
1)图片与文件在同一个文件夹,直接写图片的全名
2)图片在文件的下一级文件夹,先写文件夹名,再写文件夹下的图片全名
3)图片在文件的上一级文件夹,先写../回到上一级,再写图片全名
-->
<!-- alt图片不能正常显示时替换的文字  -->
<!-- title表示鼠标悬停在图片上显示的描述文字   -->
<img src="2.png" alt="">
<img src="img/1.jpg" alt="">
<img src="../3.png" alt="" title="我是一张五常大米的图片">
<img src="../3.pg" alt="哎呀,图片走丢了">
<!-- 使用绝对路径 -->
<!-- 如果远程服务器的资源删除，绝对路径就引用不到图片资源了  -->
<img src="https://cdn.tmooc.cn/bsfile//courseImg///5f791c0985cc4a67a5c4dca6627155b0.jpg" alt="">
<!-- width设置图片宽度 height设置图片高度
   只要设置一个,另外一个会跟着改,如果两个一起设置,注意图片的原始比例防止图片失真-->
<img src="img/zly.jpg" width="300px" height="300px" alt="">
</body>
</html>
```

### 3.5 超链接练习

# DAY02笔记 CSS基础&#x20;

## 1. 基本概念

CSS（Cascading Style Sheet）级联样式表，用来控制页面布局与页面样式

比如可以修改颜色、大小、位置、层级、动画等等

## 2. CSS 的三种位置

### 2.1 **CSS 行内样式**

写在 HTML 元素的开始标签里，只对当前行生效

特点：复用性差

```html
<h4 style="color:red;">我是标题</h4>
```

### 2.2 **CSS 内部样式**

写在 head 标签中的 style 标签里，对当前页面所有元素生效

特点：加载速度快，首页常用

```html
<head>
  <style>
     /* 标签名选择器 */
     h1 {
          color:red;
        }
  </style>
</head>
```

### 2.3 **CSS 外部样式**

写在独立的.css 文件中，在html 文件中引入外部的.css 文件

* rel：必写属性，表示引入文件是什么类型 stylesheet 样式表

* href：要引入 CSS 文件的路径

特点：可以被多个页面共享，复用性强，常用于二三级页面

```html
<html>
        <head>
                <link rel="stylesheet" href="Demo.css">
        </head>
</html>

```

### 2.4 关于优先级

* *渲染同一个元素，样式不同会叠加生效,比如背景色和文字颜色会同时生效*

* 如果渲染的样式相同，按照如下优先级排序：

* **<span style="color: rgb(216,57,49); background-color: inherit">!important&gt;行内样式&gt;（内部样式=外部样式）</span>**

* 内部样式与外部样式优先级一样，后写的样式会把之前的样式覆盖掉

  ```html
  <!DOCTYPE html>
  <html lang="en">
  <head>

      <title>CSS的三种位置</title>
      <!-- 3.外部样式,可以被多个页面引入
      rel必写属性,表明当前引入的文件是什么类型  href是被引入的CSS文件路径 -->
      <link rel="stylesheet" href="Demo.css">
      <!-- 2.内部样式,对当前页面所有元素生效   -->
      <style>
         /* 标签名选择器 */
         p {
             color: blue;
         }
         h4 {
             color: green !important;
         }
  ```

## 4.  CSS 常用值

1. **<span style="color: rgb(36,91,219); background-color: inherit">px</span>**：像素，屏幕上最小的一个发光点

2. **<span style="color: rgb(36,91,219); background-color: inherit">颜色表示法：</span>**

   * 单词表示，如：**red**

   * 十六进制表示法，如：color：**#0000FF**；

     * 前两位表示红色，中间两位表示绿色，最后两位表示蓝色

   * 简写的十六进制表示法，如：color：**#00F**；

     * 三种颜色两位数字都相同，才可以简写

   * rgb（red，green,blue）表示法，如：color：**rgb（0,0,255）**；

     * 值的范围是 0～255

   * rgba（red，green, blue，alpha）表示法，如：color：**rgba（0，0,255，0.5）**；

     * 不透明度，0 表示完全透明，1 表示完全不透明

![](images/JSD2404-基础知识模块-image-8.png)

> <span style="color: rgb(36,91,219); background-color: inherit">自然界的颜色有几百万种，但描述颜色的单词只有几百个该怎么办呢？</span>
>
> <span style="color: rgb(36,91,219); background-color: inherit">自然界中太阳光的</span>**<span style="color: rgb(36,91,219); background-color: inherit">三原色</span>**<span style="color: rgb(36,91,219); background-color: inherit">：红色 绿色 蓝色 可以通过这三种颜色调配出任意的其他颜色</span>
>
> **<span style="color: rgb(36,91,219); background-color: inherit">RGB 24 位色表示法</span>**
>
> <span style="color: rgb(36,91,219); background-color: inherit">在计算机中，使用 8 个 bit 位存储红色，8 个 bit 位存储绿色，8 个 bit 位存储蓝色，8 个 bit 位能存 2^8=256 个值，也就是 0～255，也就是 256*256*256 1677 万种色彩，人眼最多识别 300～500 万种色彩，已经超过了人眼的极限，也称作 24 位真彩色，写法：</span>**<span style="color: rgb(36,91,219); background-color: inherit">rgb（255，0，0）</span>**
>
> **<span style="color: rgb(36,91,219); background-color: inherit">RGBA 32 位色表示法  最后一个 A 是（alpha）表示不透明度参数</span>**
>
> <span style="color: rgb(36,91,219); background-color: inherit">最后 8 个 bit 位存储不透明度 1 完全不透明  0 完全透明</span>
>
> <span style="color: rgb(36,91,219); background-color: inherit">rgba（255，0，0，0.85） 表示红色，透明度 0.85</span>
>
> <span style="color: rgb(36,91,219); background-color: inherit">注意这个小数的 0 可以省略，比如 rgba（255，0，0，0.85）；可以简写成 rgba（255 ， 0 ， 0 ， .85);</span>
>
> **<span style="color: rgb(36,91,219); background-color: inherit">十六进制哈希表示法 前/中/后 两位数值分别代表 红/绿/蓝 色的色谱范围。数值从 0-9 a-f</span>**
>
> <span style="color: rgb(36,91,219); background-color: inherit">#0000FF 这里的字母大小写均可 但注意此种表示法只能表示 24 位色，没有透明度</span>
>
> **<span style="color: rgb(36,91,219); background-color: inherit">十六进制缩写表示法</span>**
>
> <span style="color: rgb(36,91,219); background-color: inherit">#00F 这里的字母大小写均可 </span>
>
> <span style="color: rgb(36,91,219); background-color: inherit">当十六进制哈希表示法的表示结果为：#0000FF </span>
>
> <span style="color: rgb(36,91,219); background-color: inherit">当每种颜色的两个数字相同时：</span>
>
> <span style="color: rgb(36,91,219); background-color: inherit">可以使用十六进制缩写表示法简写成一个数字：#00F</span>
>
> <span style="color: rgb(36,91,219); background-color: inherit">注意：如果每种颜色的两个数字不同，则不能简写，比如#808080 就不可以简写</span>

## 5. 背景图处理

**<span style="color: rgb(36,91,219); background-color: inherit">背景颜色：background-color</span>:#fff； &#x20;**

* 颜色可以使用任何的色值（十六进制 rgb rgba 单词等） 背景颜色会在元素的最底层

**<span style="color: rgb(36,91,219); background-color: inherit">背景图片插入：background-image</span>:url（路径）；**

* 注意：背景图和 img 标签的图片插入是有区别的！

* img 标签插入的图片在默认情况下直接就能显示图片

* 背景图必须给所在元素设置宽高才能显示出来

**<span style="color: rgb(36,91,219); background-color: inherit">图片重复问题：background-repeat</span>**

* **图片被平铺到元素中会出现两种情况：**

* 图片大于元素，图片显示不全

* 图片小于元素，会重复，哪个方向有空余空间，就向哪个方向重复

* **<span style="color: rgb(216,57,49); background-color: inherit">background-repeat: no-repeat; 背景图仅显示一次，不重复</span>**

* background-repeat: repeat;  默认值，X-Y 轴都重复

* background-repeat: repeat-x; 仅在 X 轴（水平方向）重复

* background-repeat: repeat-y; 仅在 Y 轴（垂直方向）重复

**<span style="color: rgb(36,91,219); background-color: inherit">背景图尺寸：background-size</span>**

* 没有设置任何尺寸时，默认使用图片本身的大小

* 设置尺寸时，<span style="color: rgb(36,91,219); background-color: inherit">值 1 </span>是背景图的<span style="color: rgb(36,91,219); background-color: inherit">宽度</span>，<span style="color: rgb(36,91,219); background-color: inherit">值 2 </span>是背景图的<span style="color: rgb(36,91,219); background-color: inherit">高度</span>

* background-size: 600px 300px;&#x20;

* background-size: 100% 100%;&#x20;

* 注意：图片比例要合适，否则会尺寸失真

**<span style="color: rgb(36,91,219); background-color: inherit">background-position</span>**<span style="color: rgb(36,91,219); background-color: inherit">:left top; </span>默认值（左上） &#x20;

* 第一个值表示水平方向 第二个值表示垂直方向

* X 轴（水平方向）的值：left 左 center 中 right 右

* Y 轴（竖直方向）的值：top 上 center 中 bottom 下

* center center 表示水平与竖直方向均居中，可以简写成一个 center

* 还可以写<span style="color: rgb(36,91,219); background-color: inherit">像素值</span>，<span style="color: rgb(216,57,49); background-color: inherit">原点（0px 0px）就是左上角</span>

* <span style="color: rgb(216,57,49); background-color: inherit">正值向右/向下移动；</span>负值向左/向上移动

**<span style="color: rgb(36,91,219); background-color: inherit">background-image: linear-gradient(270deg,red,blue);</span>**

* 线型渐变

* 可以设置多种渐变的颜色,使用逗号分隔

* 默认的角度是水平的,可以不加角度值

* 如果加了角度值,单位是deg,且角度值必须写在第一个位置

## 6. 元素的显示模式(默认的文档流 position:static)

**<span style="color: rgb(36,91,219); background-color: inherit">块级元素：display:block；</span>**

排列方式：按照书写的顺序，从上往下依次排列

特点：独占一行，还可以设置宽高

常见标签：div h1～h6 p form table ul ol li...

**<span style="color: rgb(36,91,219); background-color: inherit">行内元素：display:inline；</span>**

排列方式：按照书写顺序从左往右依次排列

特点：共占一行，不能设置宽高

常见标签：span a i b s...

**<span style="color: rgb(36,91,219); background-color: inherit">行内块元素：display:inline-block；</span>**

排列方式：按照书写顺序从左往右依次排列

特点：共占一行，可以修改宽高

常见标签：input button

**<span style="color: rgb(36,91,219); background-color: inherit">元素消失：display:none；</span>**

## 7. 字体处理

**<span style="color: rgb(36,91,219); background-color: inherit">color</span>**<span style="color: rgb(36,91,219); background-color: inherit">： </span>设置文字颜色

**<span style="color: rgb(36,91,219); background-color: inherit">font-size</span>**<span style="color: rgb(36,91,219); background-color: inherit"> ：</span>设置文字的大小

* 谷歌浏览器默认字体大小 16px，最小 12px，低于 12px 也以 12px 显示

**<span style="color: rgb(36,91,219); background-color: inherit">font-family</span>**<span style="color: rgb(36,91,219); background-color: inherit">: </span>“幼圆”； 设置文字字体

* 执行顺序是从前向后执行的

* 字体名称要使用引号包裹

* 商用字体要考虑到版权问题

* 尽量少用奇怪的字体，因为客户可能会没有

> <span style="color: rgb(36,91,219); background-color: inherit">字体文件在电脑 C 盘的“Fonts”文件夹中</span>
>
> <span style="color: rgb(36,91,219); background-color: inherit">打开“计算机”-&gt;C 盘-&gt; “Windows”-&gt; “Fonts”即可看到所有已安装的字体</span>

**<span style="color: rgb(36,91,219); background-color: inherit">font</span>**<span style="color: rgb(36,91,219); background-color: inherit">: </span>35px “微软雅黑”；字号和字体可以一起设置&#x20;

**<span style="color: rgb(36,91,219); background-color: inherit">text-decoration</span>**<span style="color: rgb(36,91,219); background-color: inherit"> ：</span>设置文本修饰线

* underline 下划线&#x20;

* <span style="color: rgb(216,57,49); background-color: inherit">none 去掉所有修饰线  </span>

* line-through 添加一条删除线

**<span style="color: rgb(36,91,219); background-color: inherit">line-height</span>**<span style="color: rgb(36,91,219); background-color: inherit">：</span>设置文本行高

* 称为行间距，指的是行与行文本之间的距离

* 如果需要单行文字在元素内<span style="color: rgb(36,91,219); background-color: inherit">垂直居中</span>，可以让<span style="color: rgb(36,91,219); background-color: inherit">行高为元素的高度</span>即可

**<span style="color: rgb(36,91,219); background-color: inherit">text-align</span>**<span style="color: rgb(36,91,219); background-color: inherit"> ：</span>设置块级元素内文本的水平对齐方式 &#x20;

* 对齐方式：left 左对齐 / center 居中对齐 / right 右对齐&#x20;

**<span style="color: rgb(36,91,219); background-color: inherit">text-shadow</span>**: 20px 20px 5px red;

* 文本阴影：X 轴偏移量 Y 轴偏移量 羽化值 阴影颜色

* lighter 300 细体

* bold 600 粗体

## 2. 流与文档流

流（Stream）：车流 水流 多个对象有序排列称为流

<span style="color: rgb(36,91,219); background-color: inherit">文档流：网页中多个元素按照自己的特性有序排列，形成了文档流</span>

如：块级从上到下排列，行内与行内块从左到右排列

<span style="color: rgb(36,91,219); background-color: inherit">文档流中元素的特点：</span>

* 依次紧密排列

* 多个 div/span 在竖直/水平方向紧挨着

* 流中的元素绝不可能出现一个元叠摞在另外一个元素上面的情况

* 如果项目中需要出现堆叠的效果，就只能"脱离文档流"

![](images/JSD2404-基础知识模块-image-19.png)

## 3. 浮动

浮动可以让块级元素横向排列

**float 属性：**

* float:left; 左浮动，向父级元素的左侧边界靠拢

* float:right; 右浮动，向父级元素右侧边界靠拢

![](images/JSD2404-基础知识模块-image-18.png)

**<span style="color: inherit; background-color: rgba(255,246,122,0.8)">浮动特点：</span>**

1. 浮动会破坏原有的文档流布局，变为浮动布局，元素可以横向排列

2. 浮动后的元素会脱离文档流，释放原有的布局空间

3. 浮动后的子元素不再支撑父元素的高度

4. 如果一个父元素中所有的子元素都浮动了，父元素会高度坍塌（失高）

**<span style="color: rgb(36,91,219); background-color: inherit">解决方案：给父元素设置 overflow:hidden；</span>**

会根据子元素浮动后的实际高度给父元素自动填充高度，解决失高问题



```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>浮动布局</title>
    <style>
        .fu {
            background-color: #ff0;
            /*子元素都浮动走,父元素会失高
            可以给父元素设置BFC结界,此时父元素会根据子元素浮动后的实际高度自动填充高度*/
            overflow: hidden;
        }
        .fu>div {
            width: 100px;
            height: 100px;
            border: 3px solid #f00;
        }
        .z1 {
            background-color: #f00;
            /* 浮动元素会脱离文档流 不再占用文档流的布局空间 也就是不再支撑父元素的高度 */
            float: left;
        }
        .z2 {
            background-color: #0f0;
            float: left;
        }
        .z3 {
            background-color: #00f;
            float: left;
        }
    </style>
</head>
<body>
<!-- .fu>.z*3 -->
<div class="fu">
    <div class="z1"></div>
    <div class="z2"></div>
    <div class="z3"></div>
</div>
</body>
</html>
```

## 4. CSS 定位

### 4.1 **静态定位（默认值）<span style="color: rgb(36,91,219); background-color: inherit"> position:static； </span>**

就是默认的文档流布局，元素处于文档流中,只能依次排列，不能随意改变自己的位置

> **<span style="color: rgb(36,91,219); background-color: inherit">使用其他定位属性后，可以让元素通过 top/bottom/left/right 四个属性移动</span>**

> **<span style="color: rgb(36,91,219); background-color: inherit">层级 z-index：</span>**&#x4F7F;用定位后，元素发生重叠时可以调整层级

> 1. z-index 的值越大，层级越高，值大的元素会覆盖值小的元素

> 2. 值为整数值，没有任何单位

> 3. 默认值是 auto，可以看作是层级 0，z-index 还可以取负值

### 4.2 相对定位<span style="color: rgb(36,91,219); background-color: inherit"> </span>**<span style="color: rgb(36,91,219); background-color: inherit">position:relative； </span>**

**<span style="color: rgb(36,91,219); background-color: inherit">移动参照物：元素自己原来的位置</span>**

1. 不会脱离文档流并保留原有位置，还可以支撑父元素，不影响父级

2. 与外间距 margin 的区别：margin 会影响其他元素，相对定位不会挤开兄弟元素，但可能会遮盖

3. 常用于需要微调元素位置时使用

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>相对定位</title>
    <style>
        .fu {
            background-color: #ff0;
        }
        .fu>div {
            width: 100px;
            height: 100px;
        }
        .z1 {
            background-color: #f00;
            /* 注意!要先加position才能移动位置 调整层级 */
            position: relative;
            z-index: 10;/*整数 默认0 数值越大 层级越高 */
            left: 25px;
        }
        .z2 {
            background-color: #0f0;
            /*相对定位
            移动参照物:自己原来的位置
            不脱离文档流 不释放布局空间 也不会挤开其它元素*/
            position: relative;
            left: 50px;
            bottom: 50px;
            z-index: -1;
        }
        .z3 {
            background-color: #00f;
        }
    </style>
</head>
```

| --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------ |
|                                                                                                                                                                                         | **2）如果所有子元素都浮动，父元素会<span style="color: rgb(216,57,49); background-color: inherit">高度坍塌</span>**                          |
|                                                                                                                                                                                         | **3）浮动元素可以使用 margin 微调自己的位置**                                                                                            |
|                                                                                                                                                                                         | **4）用途：可在页面中实现"两端对齐"或“<span style="color: rgb(216,57,49); background-color: inherit">横置</span>”的效果**                     |
| **<span style="color: rgb(36,91,219); background-color: inherit">静态定位（默认文档流布局）</span>**<br />**<span style="color: rgb(36,91,219); background-color: inherit">position:static;</span>** | **1） 块级元素从上往下依次排列**                                                                                                      |
|                                                                                                                                                                                         | **2）行内/行内块元素从左往右依次排列，一行放不下才换行**                                                                                          |

| **<span style="color: rgb(36,91,219); background-color: inherit">相对定位</span>**<br />**<span style="color: rgb(36,91,219); background-color: inherit">position:relative;</span>**        | **<span style="color: rgb(216,57,49); background-color: inherit">1）移动参照物：自己作为静态定位元素时原来的位置</span>**                       |
|                                                                                                                                                                                         | **2）不会脱离文档流、不会释放布局空间**                                                                                                   |
|                                                                                                                                                                                         | **3）可以使用 top bottom left right 调整自己的位置**                                                                                 |
|                                                                                                                                                                                         | **4）可以使用 z-index 调整层级**                                                                                                  |
|                                                                                                                                                                                         | **5）用途：微调自己的位置，但不会挤开其它元素**                                                                                               |
|                                                                                                                                                                                         | **6）用途：为使用绝对定位的后代元素提供定位参照物**                                                                                             |
| **<span style="color: rgb(36,91,219); background-color: inherit">绝对定位</span>**<br />**<span style="color: rgb(36,91,219); background-color: inherit">position:absolute;</span>**        | **<span style="color: rgb(216,57,49); background-color: inherit">1）移动参照物：离自己最近的使用了非 static 定位的上级元素，终点是 html 根元素</span>** |
|                                                                                                                                                                                         | **2）会脱离文档流并且释放布局空间**                                                                                                     |
|                                                                                                                                                                                         | **3）可以使用 top bottom left right 调整自己的位置**                                                                                 |
|                                                                                                                                                                                         | **4）可以使用 z-index 调整层级**                                                                                                  |
|                                                                                                                                                                                         | **5）用途：在页面上覆盖到其它元素上方的指定位置**                                                                                              |
| **<span style="color: rgb(36,91,219); background-color: inherit">固定定位</span>**<br />**<span style="color: rgb(36,91,219); background-color: inherit">position:fixed;</span>**<br />     | **<span style="color: rgb(216,57,49); background-color: inherit">1）移动参照物：html 根元素</span>**                               |
|                                                                                                                                                                                         | **2）会脱离文档流并且释放布局空间**                                                                                                     |

|                                                                                                                                                                                         | **4）可以使用 z-index 调整层级**                                                                                                  |
|                                                                                                                                                                                         | **5）用途：制作覆盖整个窗口的遮罩层、或制作页面固定广告**                                                                                          |

## 7. 元素的放大与过渡

* **<span style="color: rgb(36,91,219); background-color: inherit">transform: scale(</span> <span style="color: rgb(222,120,2); background-color: inherit">n</span> <span style="color: rgb(36,91,219); background-color: inherit">); </span>**&#x53D8;换:放大(倍数) 放大至原来的n倍

  * n>1放大n倍  n=1 大小不变  0\<n<1缩小n倍 0缩小到看不见

* **<span style="color: rgb(36,91,219); background-color: inherit">transition: </span> <span style="color: rgb(222,120,2); background-color: inherit">2s</span> <span style="color: rgb(36,91,219); background-color: inherit">;</span>** 添加过渡 让变换有一点过渡时间，不要一瞬间完成 太突兀

* **注意:&#x20;**&#x8FC7;渡要加给div，而不是悬停,否则离开 div 时没有过渡,效果不好

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>元素放大与过渡</title>
    <style>
        div {
            width: 100px;
            height: 100px;
            background-color: #f00;
            margin: 100px auto 0; /*外间距: 上 左右 下*/
            /*过渡时间 注意不要加在:hover中,否则不悬停时就没有过渡效果了*/
            transition: 2s;
        }
        div:hover {
            background-color: #0aa1ed;
            /*变换:缩放(n)
            n>1放大n倍  n=1 大小不变  0<n<1缩小n倍 0缩小到看不见*/
            transform: scale(2);
            border-radius: 50px;
        }
    </style>
</head>
<body>
    <div></div>
</body>
</html>
```

## 11. 元素溢出

## 5. MVC 与 MVVM

**<span style="color: rgb(216,57,49); background-color: inherit">M</span> <span style="color: rgb(46,161,33); background-color: inherit">V</span> <span style="color: rgb(36,91,219); background-color: inherit">C </span>**&#x8BBE;计模式就是将实现前端业务的所有代码划分为三部分

* **<span style="color: rgb(216,57,49); background-color: inherit">M</span>**: <span style="color: rgb(216,57,49); background-color: inherit">Model</span> 模型 ， 对应数据相关代码

* **<span style="color: rgb(46,161,33); background-color: inherit">V</span>**: <span style="color: rgb(46,161,33); background-color: inherit">View </span>视图， 对应的是页面标签相关

* **<span style="color: rgb(36,91,219); background-color: inherit">C</span>**: <span style="color: rgb(36,91,219); background-color: inherit">Controller </span>控制器， 对应的是将数据显示到页面中的过程代码

**MVC 设计模式的弊端：&#x20;**&#x43;ontroller 需要频繁的进行 DOM 相关操作（遍历查找元素），比较浪费资源&#x20;

MVVM 设计模式就很好的解决了这个问题：

**<span style="color: rgb(216,57,49); background-color: inherit">M</span> <span style="color: rgb(46,161,33); background-color: inherit">V</span> <span style="color: rgb(36,91,219); background-color: inherit">VM </span>**&#x8BBE;计模式也是将实现前端业务的所有代码划分为三部分

* **<span style="color: rgb(216,57,49); background-color: inherit">M</span>**: <span style="color: rgb(216,57,49); background-color: inherit">Model</span> 模型 ， 对应数据相关代码(数据)

* **<span style="color: rgb(46,161,33); background-color: inherit">V</span>**: <span style="color: rgb(46,161,33); background-color: inherit">View</span> 视图， 对应的是页面标签相关(页面)

* **<span style="color: rgb(36,91,219); background-color: inherit">VM</span>**:<span style="color: rgb(36,91,219); background-color: inherit">ViewModel</span> 视图模型，直接将页面元素与变量进行绑定

  * 视图模型负责将页面中可能发生改变的元素和某个变量在内存中进行绑定&#x20;

  * 对变量进行监听，当变量发生改变时，会从内存中找到和变量所对应的元素， 让元素进行改动&#x20;

这样就不用像 MVC 设计模式中通过遍历查找的方式查找元素了，大大提高了执行的效率

### 6.6 隐藏显示指令练习 FView.vue

**<span style="color: rgb(36,91,219); background-color: rgba(255,246,122,0.8)">v-if=&quot;变量&quot;</span>**：控制元素是否显示

* true 显示，false 不显示

* 直接在DOM中跳过该元素渲染,HTML代码中没有该元素

* 元素首次渲染需要复杂计算或初始化,v-if初次加载的速度快,推荐使用

**<span style="color: rgb(36,91,219); background-color: rgba(255,246,122,0.8)">v-else</span>：** 和最近的未关闭的 v-if 状态取反

**<span style="color: rgb(36,91,219); background-color: rgba(255,246,122,0.8)">v-show=&quot;变量&quot;</span>**：控制元素是否显示

* true 显示，false 不显示（隐藏元素）

* 通过设置CSS display:none;让元素消失

* 当元素需要频繁修改显示状态时推荐使用,不用多次新建删除元素,开销较小

```html
<template>
  <h1>隐藏显示指令</h1>
  <!-- v-if="布尔值" true元素显示 false元素消失
  false表示该元素不会被渲染到DOM中,会直接跳过这部分内容的渲染 -->
  <p v-if="true">张三</p>
  <p v-if="false">李四</p>
  <p>王五</p>
  <hr>
  <p v-if="isShow">月亮</p>
  <p v-if="isShow">星星</p>
  <!-- v-else是v-if取反 它会找离自己最近的v-if进行取反 -->
  <p v-else>太阳</p>
  <hr>
  <!-- v-if是直接在DOM中跳过该元素渲染,HTML代码中没有该元素 -->
  <p v-if="false">小绿</p>
  <!-- v-show是修改元素的CSS属性display:none;在频繁切换是否显示时才推荐,性能更好 -->
  <p v-show="false">小红</p>
</template>

<script setup>
import {ref} from "vue";

const isShow = ref(false);
</script>

<style scoped>

</style>
```

## 7. VUE指令总结

1. **<span style="color: inherit; background-color: rgba(183,237,177,0.8)">{{变量}}</span>**：插值，让此处&#x7684;**<span style="color: rgb(216,57,49); background-color: inherit">文本内容</span>**&#x548C;变量进行绑定

2. **<span style="color: inherit; background-color: rgba(183,237,177,0.8)">v-text=&quot;变量&quot;</span>**：&#x8BA9;**<span style="color: rgb(216,57,49); background-color: inherit">元素的文本内容</span>**&#x548C;变量进行绑定

3. **<span style="color: inherit; background-color: rgba(183,237,177,0.8)">v-html=&quot;变量&quot;</span>**：让元素&#x7684;**<span style="color: rgb(216,57,49); background-color: inherit"> html 标签内容</span>**&#x548C;变量进行绑定

4. **<span style="color: inherit; background-color: rgba(183,237,177,0.8)">v-bind:属性名=&quot;变量&quot;</span>**：让 xxx **<span style="color: rgb(216,57,49); background-color: inherit">属性的值</span>**&#x548C;变量进行绑定，简写是把 v-bind 去掉

5. **<span style="color: inherit; background-color: rgba(183,237,177,0.8)">v-model=&quot;变量&quot;</span>**：&#x8BA9;**<span style="color: rgb(216,57,49); background-color: inherit">控件的值</span>**&#x548C;**<span style="color: rgb(216,57,49); background-color: inherit">变量</span>**&#x8FDB;行双向绑定

应用场景：当需要获取用户输入内容时使用

（当变量的值改变时，控件的值会随之改变；当控件中用户输入的值改变时，变量的值也会随之改变）

* **<span style="color: inherit; background-color: rgba(183,237,177,0.8)">v-on:事件名=&quot;方法&quot;</span>**：**<span style="color: rgb(216,57,49); background-color: inherit">事件</span>**&#x7ED1;定，简写@事件名

* **<span style="color: inherit; background-color: rgba(183,237,177,0.8)">v-for=&quot;(变量,下标) in 数组&quot;</span>**：循环遍历指令，遍历的过程中生成遍历到的当前元素

* **<span style="color: inherit; background-color: rgba(183,237,177,0.8)">v-if=&quot;变量&quot;</span>**：控制元素是否显示，true 显示，false 不显示（**<span style="color: rgb(216,57,49); background-color: inherit">直接不渲染该元素</span>**）

* **<span style="color: inherit; background-color: rgba(183,237,177,0.8)">v-else</span>** 和 v-if 的状&#x6001;**<span style="color: rgb(216,57,49); background-color: inherit">取反</span>**

* **<span style="color: inherit; background-color: rgba(183,237,177,0.8)">v-show=&quot;变量&quot;</span>**：控制元素是否显示，true 显示，false 不显示（**<span style="color: rgb(216,57,49); background-color: inherit">隐藏元素</span>**）

```javascript
const debounce = (fn, delay) => {
    let timer = null;
    return function () {
        let context = this;
        let args = arguments;
        clearTimeout(timer);
        timer = setTimeout(function () {
            fn.apply(context, args);
        }, delay);
    }
}
const _ResizeObserver = window.ResizeObserver;
```
